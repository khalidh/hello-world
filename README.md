# hello-world

RAP Hello World examples for SAP BTP Trial import via abapGit and Eclipse ADT.

## Included

- rap-hello-world-btp-trial-uuid-etag: RAP managed app with UUID + ETag + seed report

## Quick start

1. Open abapGit in your ABAP BTP trial system.
2. Import this repository (`New Online`).
3. Refresh package in ADT.
4. Create/publish Service Binding for `ZUI_HELLO_U`.
5. Run `ZLOAD_HELLO_U` report.
